# digital-interaction

数字交互作品集，汇集作者自主开发的数字交互示例、工程教学演示与可视化实验。

## 项目入口

- [GTC-8C probe](./GTC-8C-probe/)：GTC-8C 探头布局数字交互示例
- [高速铁路桥上无砟轨道几何形位调整课件](./rail-geometry-courseware/)：桥上无砟轨道几何形位调整教学课件
- [轨道智护先锋](./railway-guardian-pioneer-app/)：铁路营业线施工安全监管与 SOP 管控系统

- [钻孔灌注桩施工工序挑战](./drilled-pile-sequence/)：通过动画和填空梳理12步施工工序
- [正反循环流向判断](./drilling-circulation/)：观察泥浆流向动画并完成判断
- [钻孔桩常见缺陷及防治](./drilled-pile-defects/)：结合现场情境进行质量判断并查阅缺陷图文资料

- [桥梁上部结构能力图谱（任务1.1）](./bridge-competency-map/)：五级能力图谱，支持自动轮播、节点联动和动态流光连线
